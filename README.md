# Кіно українською у Вроцлаві (застосунок)

Вебзастосунок з іконкою на телефоні й компʼютері: вводите «завтра», «субота», «25.10», «з 20 по 25», «вихідні», назву фільму («Веріті») чи кінотеатр («Multikino») і одразу бачите картки фільмів з українськими назвами, описами й сеансами з посиланнями на квитки.

Попередня версія (скрипт, який запускає Claude у проєкті) лишається запасною «альфою» в `kino-wroclaw/` і `kino-wroclaw-alpha/`.

## Як це працює

- `kino_ua.py` збирає сеанси з Cinema City, Multikino (через Filmweb), Helios, Kino Nowe Horyzonty, DCF і DKF Politechnika. Українські назви й описи: TMDB, далі Планета Кіно, далі `synopsis_uk.json`. Multiplex не використовується.
- `build.py` запускає його на 14 днів уперед і записує `site/data.json`.
- `extras.py` додає до кожного фільму український трейлер (пошук YouTube), рейтинг IMDb (офіційний набір datasets.imdbws.com, ідентифікатор фільму з TMDB) і Rotten Tomatoes (через OMDb, якщо задано ключ `OMDB_API_KEY`). Сторінки IMDb і Rotten Tomatoes роботів GitHub не пускають, тому напряму їх не читаємо. Якщо трейлер не знайдено, значок YouTube веде на пошук трейлера.
- `.github/workflows/update.yml` щогодини (і після кожного Merge у `main`) запускає `build.py` і публікує папку `site/` на GitHub Pages.
- `site/` це сам застосунок: шукає по `data.json` у браузері, тому відповідає миттєво і працює офлайн з останнім завантаженим розкладом.
- Якщо щось потребує уваги (кінотеатр не відповідає, фільм без українського опису, розклад давно не оновлювався), у застосунку зʼявляється знак «!», який відкриває сторінку з деталями. Окремий крок робота не дає GitHub вимкнути розклад через 60 днів без змін у репозиторії.

Пошук розуміє дати («завтра», «у суботу», «25.10», «25 жовтня», «з 20 по 25», «з пʼятниці по неділю», «до неділі», «з 25», «вихідні», «тиждень», «наступного тижня», «усі»), час («19:50», «після 18», «ввечері»), назви фільмів польською, українською чи латинкою з опечатками («verity», «вертіі»), жанр («жахи»), кінотеатр і формат («multikino», «2d»). Слова, яких немає в розкладі, пропускаються з приміткою, щоб не ховати решту результатів.

Безпека: на сторінці діє суворий CSP (лише власні файли), шрифти лежать у `site/fonts`, посилання з сайтів кінотеатрів пропускаються лише як https, дії GitHub закріплені за відбитком коміту, а кожен крок робота має лише потрібні йому права.

Описи, яких немає українською ні в TMDB, ні в Планеті Кіно, показуються польською сірим кольором. Щоб додати переклад, допишіть його в `synopsis_uk.json` (ключ видно в `data.json`, поле `key`).

## Налаштування (один раз)

1. Settings → Pages → Source: **GitHub Actions**.
2. Settings → Secrets and variables → Actions → New repository secret: `TMDB_API_KEY` (ключ TMDB для українських назв і описів).
   Для рейтингу Rotten Tomatoes ще `OMDB_API_KEY`: безкоштовний ключ з https://www.omdbapi.com/apikey.aspx (тариф FREE, ключ приходить на пошту, його треба активувати посиланням з листа). Без нього Rotten Tomatoes просто не показується.
3. Actions → «Оновити розклад» → Run workflow. Адреса застосунку зʼявиться в результаті запуску.

## Встановити як застосунок

- Android / Chrome на ПК: відкрити адресу, меню → «Встановити застосунок» (або «Додати на головний екран»).
- iPhone: відкрити в Safari → «Поділитися» → «На початковий екран».

## Локальна перевірка

```
python3 build.py 3                       # 3 дні замість 14
python3 -m http.server -d site 8000      # відкрити http://localhost:8000
```
